# 朋友局德州扑克联机版

这是一个“分享链接进房间、各自手机上桌”的德州扑克娱乐筹码网页项目。

## 功能

- 创建房间，生成邀请链接
- 朋友用手机打开链接，输入昵称入座
- 每个玩家只看到自己的手牌
- 公共牌、底池、下注、筹码实时同步
- 支持 2-9 人
- 按钮位、大小盲自动轮转
- 弃牌、过牌、跟注、下注、加注、All-in
- 自动摊牌判定牌型
- 支持基础边池结算
- 房主可以设置初始筹码、大小盲、开始下一手、重置筹码

## 本地运行

电脑安装 Node.js 18 或以上版本后：

```bash
npm install
npm start
```

然后浏览器打开：

```text
http://localhost:3000
```

创建房间后，把页面里的邀请链接发给朋友即可。

## 部署到公网

这个版本需要一个 Node.js 服务器，因为多人联机需要 WebSocket 实时同步。

可部署到：

- Railway
- Render
- Fly.io
- 自己的云服务器
- 宝塔面板 Node 项目

部署参数：

```text
Start Command: npm start
Node Version: 18+
Port: 使用平台自动分配的 PORT 环境变量
```

部署完成后，你会得到一个公网域名，例如：

```text
https://your-app-name.onrender.com
```

打开这个域名，创建房间，复制邀请链接发给朋友即可。

## 注意

1. 这是娱乐筹码版，不包含真钱、支付、抽水功能。
2. 当前房间数据保存在服务器内存里，服务器重启后房间会消失。
3. 如果要长期使用，下一版建议接数据库，比如 Redis / PostgreSQL / Supabase。
4. 如果要做成商业级，还需要加：
   - 用户账号
   - 房间密码
   - 断线重连保护
   - 管理员后台
   - 防作弊日志
   - 更严格的边池和短筹码规则
   - 手机端横屏专用界面
